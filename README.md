## Introduction

**PokéStash** is a Pokémon-themed inventory tracking application where users can register, manage their personal item bag, and perform CRUD operations on items to keep up with changes in the game. Built with Java 17 and Spring Boot for streamlined configuration, the application features a CSS/Bootstrap interface and uses GitHub for version control and collaboration
