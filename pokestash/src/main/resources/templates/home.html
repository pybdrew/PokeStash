Poké Bag / Store Emulator

This application is a Poké Bag / Item Store emulator where users can browse items, add them to their personal bag, modify quantities, or remove items. Prices are not used, as the application is intended for learning cloud computing concepts and developing partner collaboration skills.

The backend is built using Spring Boot, with security features such as password hashing for user accounts. The system demonstrates CRUD operations, user authentication, and management of user-specific inventory in a cloud-friendly setup.
